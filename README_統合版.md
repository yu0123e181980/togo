# カテゴリーマネジメントツール統合版

7つのデータ分析HTMLツールを1つのファイルに統合した、包括的なカテゴリーマネジメントツールです。

## 📊 含まれるツール

1. **棚割データ処理ツール** - 棚割データの加工とZIP出力
2. **収益分析ツール** - バブルチャートによる多次元分析
3. **売上分解ツリー** - SVGツリーによる売上要因の階層分解
4. **売上分解表** - 表形式による詳細な売上分解
5. **顧客分析ツール** - 年代・ライフステージ・来店距離分析
6. **ビジュアルベンチマークツール** - Chart.jsによる多角的ベンチマーク分析
7. **ABC分析ツール** - 商品の重要度分類と優先順位付け

## 🚀 使い方

### 1. 環境準備

#### 対応ブラウザ
- ✅ Google Chrome（最新版）推奨
- ✅ Microsoft Edge（最新版）
- ✅ Opera（最新版）
- ❌ Firefox、Safari（File System Access API非対応）

#### 必要なファイル
以下の7つのExcelファイルを同一フォルダに配置してください：

```
your_data_folder/
├── shelf_data.xlsx          # 棚割データ処理用
├── profit_analysis.xlsx     # 収益分析用
├── sales_tree.xlsx          # 売上分解ツリー用
├── sales_breakdown.xlsx     # 売上分解表用
├── customer_analysis.xlsx   # 顧客分析用
├── visual_benchmark.xlsx    # ビジュアルベンチマーク用
└── abc_analysis.xlsx        # ABC分析用
```

**注意**: ファイル名は大文字小文字を含めて完全に一致させてください。

### 2. ツールの起動

1. `all_tools_integrated.html` をChrome/Edgeで開く
2. 約2.5秒のスプラッシュスクリーン表示を待つ
3. 外部ライブラリ使用承認画面で **「同意して開始」** をクリック

### 3. フォルダの選択

1. **フォルダ選択タブ** で **「📁 フォルダを選択」** ボタンをクリック
2. Excelファイルが保存されているフォルダを選択
3. 7つのファイルの検出状況を確認
   - ✅ 緑チェック: ファイルが検出されました
   - ❌ 赤バツ: ファイルが見つかりません

### 4. ツールの使用

各ツールのタブに切り替えて、データ分析を開始できます。

## 📖 各ツールの使い方

### 1️⃣ 棚割データ処理ツール

**用途**: 棚割データをCSV形式に変換してZIP出力

**使用手順**:
1. タブ「棚割データ処理」に切り替え
2. 「shelf_data.xlsx を読み込む」エリアをクリック
3. フォルダ構成を選択（店舗別 or 棚名称別）
4. 「データ処理を開始」ボタンをクリック
5. ZIPファイルがダウンロードされます

**出力内容**:
- 店舗別/棚名称別に整理されたCSVファイル（Shift_JISエンコード）
- 出力ファイル一覧.csv

---

### 2️⃣ 収益分析ツール

**用途**: バブルチャートによる多次元収益分析

**使用手順**:
1. タブ「収益分析」に切り替え
2. profit_analysis.xlsxを読み込む
3. モード選択（標準分析/クロス分析）
4. フィルター設定（商品分類、タイプ分類）
5. 分析結果を確認

**主な機能**:
- 17種類の指標表示（売上高、荒利率、前年比など）
- バブルチャートによる多次元分析
- 階層ドリルダウン機能
- 表・グラフの画像ダウンロード

---

### 3️⃣ 売上分解ツリー

**用途**: SVGツリーによる売上要因の視覚的分解

**使用手順**:
1. タブ「売上分解ツリー」に切り替え
2. sales_tree.xlsxを読み込む
3. 分析基準、タイプ分類、分析粒度を選択
4. 必要に応じて階層フィルターで絞り込み
5. 「分解表を作成」ボタンをクリック

**分解構造**:
```
購入金額
├─ 購入金額（会員）
│  ├─ POS客数
│  │  ├─ ID客数
│  │  └─ 購入頻度
│  └─ 1回あたり購入金額
│     ├─ 1回あたり購入点数
│     └─ 平均売価
└─ 購入金額（非会員）
   ├─ POS客数
   └─ 1回あたり購入金額
      ├─ 1回あたり購入点数
      └─ 平均売価
```

**表示オプション**:
- ☑ 購入率を表示
- ☑ ディビジョン全体を表示（デュアルツリー）

---

### 4️⃣ 売上分解表

**用途**: 表形式による詳細な売上分解分析

**使用手順**:
1. タブ「売上分解表」に切り替え
2. sales_breakdown.xlsxを読み込む
3. 分析基準、タイプ分類、分析粒度を選択
4. テーブルが表示されます

**主な機能**:
- 当年値と昨対値の並列表示
- 階層ドリルダウン/ドリルアップ
- パンくずナビゲーション
- 全指標のソート機能
- テーブルの画像ダウンロード

**表示指標**:
- 売上高
- ID客数、POS客数
- 来店頻度
- 1回あたり点数、1回あたり購入金額
- 平均単価
- 購入率

---

### 5️⃣ 顧客分析ツール

**用途**: 年代・ライフステージ・来店距離別の顧客分析

**使用手順**:
1. タブ「顧客分析」に切り替え
2. customer_analysis.xlsxを読み込む
3. 階層スライサーでフィルタリング（7階層）
4. 表示項目を選択（年代/ライフステージ/来店距離）
5. テーブルまたはドリルダウンで詳細確認

**主な機能**:
- 7階層の階層スライサー
- ドリルダウン機能（階層的なデータ探索）
- テーブルソート機能
- 列のドラッグ&ドロップ並び替え
- 全体ドリルダウンボタン
- 画像ダウンロード

---

### 6️⃣ ビジュアルベンチマークツール

**用途**: Chart.jsによる多角的なベンチマーク分析

**使用手順**:
1. タブ「ビジュアルベンチマーク」に切り替え
2. visual_benchmark.xlsxを読み込む
3. モード選択（階層分析/任意項目分析/価格戦略分析）
4. フィルター設定
5. 分析結果を確認

**3つのモード**:

#### 階層分析モード
- カテゴリー、企業名、店舗、棚名称でフィルタリング
- 階層ドリルダウン
- 4種類のグラフ切り替え（SKU数、構成比、フェイス数、構成比）

#### 任意項目分析モード
- X軸/Y軸の指標を自由に選択
- バブルチャート表示

#### 価格戦略分析モード
- プライスライン分析
- 商品マトリクスポップアップ

---

### 7️⃣ ABC分析ツール

**用途**: 商品の重要度分類と優先順位付け

**使用手順**:
1. タブ「ABC分析」に切り替え
2. abc_analysis.xlsxを読み込む
3. 階層フィルター設定（5階層）
4. ABC判定基準設定
   - 売上累積構成比（A/B/C）
   - リピート率（A/B/C）
5. 「ABC分析を実行」ボタンをクリック

**ABC判定種類**:
- 売上金額ABC（累積構成比ベース）
- 売上金額/1店ABC
- 推定売上金額/1店ABC
- リピート率ABC

**カラーコード**:
- 🔵 **A**: 青色（重要度: 高）
- 🔵 **B**: 水色（重要度: 中）
- 🟡 **C**: 黄色（重要度: 低）

**主な機能**:
- 8種類の実行後フィルター
- 列選択チェックボックス
- ドラッグ&ドロップで列並び替え
- ソート機能（3状態: 昇順/降順/解除）
- Excelエクスポート（色分け保持）

## 🛠️ 技術仕様

### 使用ライブラリ
- **SheetJS (xlsx)** 0.18.5 - Excelファイル処理
- **PapaParse** 5.3.2 - CSV解析
- **JSZip** 3.10.1 - ZIP圧縮
- **FileSaver.js** 2.0.5 - ファイルダウンロード
- **encoding.js** 2.0.0 - Shift_JIS変換
- **html2canvas** 1.4.1 - HTML要素の画像化
- **Chart.js** 3.9.1 - グラフ描画

### ブラウザAPI
- **File System Access API** - フォルダベースのファイル管理

### データ処理
- ブラウザ内完結型（サーバー送信なし）
- ローカルストレージ/セッションストレージ不使用
- File System Access APIによる安全なファイルアクセス

---

## 📌 制限事項・注意点

### 1. ブラウザ制限
- File System Access APIに対応したブラウザのみ使用可能
- Firefox、Safariでは動作しません

### 2. ファイル配置
- 7つのExcelファイルは**同一フォルダ**に配置必須
- ファイル名は**完全一致**必須（大文字小文字含む）

### 3. データ形式
- 各Excelファイルは元のツールと同じフォーマット
- 列名は完全一致必須

### 4. ネットワークドライブ
- File System Access APIの制約により、一部のネットワークドライブでは動作しない可能性があります
- ローカルドライブでの使用を推奨

### 5. パフォーマンス
- 大容量データ（数万行以上）の場合、処理に時間がかかる可能性があります
- メモリ使用量が多い場合、ブラウザがフリーズする可能性があります

## 🔧 トラブルシューティング

### Q1. フォルダ選択ボタンが動作しない
**A1**. 対応ブラウザ（Chrome/Edge/Opera）を使用しているか確認してください。

### Q2. Excelファイルが検出されない
**A2**. 以下を確認してください：
- ファイル名が完全に一致しているか（大文字小文字含む）
- ファイルが選択したフォルダ内に存在するか
- ファイルの拡張子が`.xlsx`であるか

### Q3. データ読み込み時にエラーが発生する
**A3**. 以下を確認してください：
- Excelファイルのフォーマットが正しいか
- 必要な列が存在するか
- データに不正な値が含まれていないか

### Q4. グラフが表示されない
**A4**. 以下を試してください：
- ブラウザをリロードする
- ブラウザのコンソール（F12）でエラーを確認する
- 異なるデータセットで試す

### Q5. 画像ダウンロードが動作しない
**A5**. ブラウザのポップアップブロックを解除してください。

## 🎯 開発者向け情報

### ファイル構造
```
all_tools_integrated.html
├── <style> - 全ツールのCSSスコープ分離
│   ├── 共通スタイル
│   ├── #tabContent1 - 棚割データ処理
│   ├── #tabContent2 - 収益分析
│   ├── #tabContent3 - 売上分解ツリー
│   ├── #tabContent4 - 売上分解表
│   ├── #tabContent5 - 顧客分析
│   ├── #tabContent6 - ビジュアルベンチマーク
│   └── #tabContent7 - ABC分析
│
├── <body> - HTMLマークアップ
│   ├── スプラッシュスクリーン
│   ├── ライブラリ承認モーダル
│   └── メインコンテンツ
│       ├── タブナビゲーション
│       └── タブコンテンツ（8つ）
│
└── <script> - JavaScript実装
    ├── 共通関数
    │   ├── readExcelFile()
    │   ├── showError()
    │   ├── showLoading()
    │   └── switchTab()
    │
    └── ツール別実装（IIFE内でスコープ分離）
        ├── initShelfDataTool()
        ├── initProfitAnalysisTool()
        ├── initSalesTreeTool()
        ├── initSalesBreakdownTool()
        ├── initCustomerAnalysisTool()
        ├── initVisualBenchmarkTool()
        └── initABCAnalysisTool()
```

### カスタマイズ方法
各ツールは独立したスコープ内で実装されているため、個別にカスタマイズ可能です。

1. **CSS変更**: 対応する`#tabContentN`セレクタ内のスタイルを変更
2. **JavaScript変更**: 対応するIIFE内のコードを変更
3. **HTML変更**: 対応する`tabContentN`セクション内のマークアップを変更
